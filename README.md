## Description
Implementation of Projects 7 and 8 of the [nand2tetris course](https://www.nand2tetris.org/), a MOOC (Massive Open Online Course) that teaches students how to build a computer system from the ground up and how to write assemblers, compilers, and high-level languages that run on the system you designed. This software suite allows users to directly parse and translate VM code (.vm) into assembly code (.asm), as specified in the nand2tetris project requirements.

Consult 'bin/example_vmcode.vm' and 'bin/example_vmcode.asm' for example VM code and its assembly translation, respectively.
